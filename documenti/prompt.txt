Prompt 1: Setup dell'Ambiente e Configurazione Server

    "Iniziamo la creazione del progetto 'ANIMA ANTICA'. Configura la struttura delle cartelle: una root server/ per il backend e una cartella public/ per il frontend. Inizializza un file package.json includendo come dipendenze: express, socket.io, peer (per il server di signaling WebRTC), bcrypt per la sicurezza delle password, e dotenv. Crea il file server/server.js configurato con Express e Socket.io. Implementa una logica di base per gestire le connessioni socket, mantenendo un array o un oggetto per tracciare gli utenti online (nick, stato occupato/libero, socketID). Assicurati di includere middleware di sicurezza base per HTTP headers (come helmet) e commenta il codice per spiegare la gestione della sicurezza."

Prompt 2: Database e Sistema Utenti

    "Ora implementa la gestione utenti nel server. Crea un file server/db.js (puoi usare un approccio semplice con MongoDB/Mongoose o un file JSON locale per ora, come preferisci). Implementa le funzioni per: registrazione utente (criptando la password con bcrypt), login, e aggiornamento dello stato (libero/occupato). Crea gli endpoint API necessari in server/server.js per gestire le richieste di registrazione e login provenienti dal frontend. Assicurati che ogni input sia validato per prevenire SQL injection o XSS."

Prompt 3: Interfaccia Principale (Frontend)

    "Crea i file public/index.html e public/style.css.

        In index.html: inserisci il titolo 'ANIMA ANTICA' con effetto gradiente arcobaleno, i due bottoni richiesti (Login/Reg in verde, Webcam On/Off in blu, scritte rosse), e un container per la griglia di video.

        In style.css: imposta lo sfondo 'cielo notturno stellato' (usa un gradiente scuro con piccoli elementi circolari bianchi posizionati casualmente) e posiziona la luna sul margine destro. Usa Flexbox/Grid per rendere la griglia responsiva.

        Implementa in public/js/main.js la logica per attivare la webcam usando navigator.mediaDevices.getUserMedia e mostrare il feed nel riquadro dell'utente stesso nella griglia."

Prompt 4: Logica WebRTC e Sistema di Chiamata

    "Implementa il cuore della videochat usando PeerJS.

        Integra PeerJS nel frontend per gestire la connessione P2P.

        Implementa la logica di chiamata: quando un utente clicca sul riquadro di un altro, invia una richiesta tramite socket.emit('call-request').

        Gestisci la ricezione della richiesta con un toast in basso a destra.

        Se il chiamato accetta, avvia la connessione WebRTC. Se è 'occupato', invia un messaggio di feedback al chiamante.

        Assicurati che, in caso di rifiuto, il server invii un segnale di chiusura a entrambi e rimuova lo stato di 'chiamata in corso'."

Prompt 5: Pagina di Chat Privata e Messaggistica

    "Crea public/chat.html e public/js/chat.js.

        La pagina deve visualizzare il video dell'interlocutore in full-screen (utilizzando l'oggetto MediaStream di WebRTC) e la propria webcam in un riquadro piccolo in alto a destra.

        Implementa la barra di testo in basso per la chat.

        Configura socket.io per inviare e ricevere i messaggi testuali tra i due peer nella stanza privata.

        Inserisci la logica per il pulsante 'blocca utente': quando attivato, aggiorna il database sul server per impedire future chiamate da quell'ID utente."

Note importanti per l'esecuzione:

    Sicurezza: Quando l'assistente genera il codice, controlla sempre che le password non siano mai stampate nei log del server.

    HTTPS: Ricorda che per testare la webcam dovrai far girare il server locale in HTTPS (puoi generare un certificato auto-firmato) o usare localhost (che i browser considerano sicuro).

    Modularità: Se il file server.js diventa troppo grande, chiedi all'assistente di "spezzare la logica in controller separati" (es. authController.js, socketController.js).
